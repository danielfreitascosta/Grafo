# Grafo
Classe GMA para gerenciar Grafos via Matriz de Adjacência. O construtor define o número de vértices e se as arestas são direcionais ou bidirecionais. Possui métodos para adicionar/remover vértices (validando o tipo de aresta), inserir arestas com ou sem peso (ajustando a matriz dinamicamente) e exibir a matriz de adjacências gerada.
